#  Lipophilicity (LogD) 预测项目

## 1. 任务简介

本项目基于 MoleculeNet 中的 Lipophilicity 数据集，旨在构建一个从分子的 SMILES 结构预测其脂溶性（LogD，即 `exp` 列）的回归模型。项目包含了从数据清洗、特征工程、数据集划分（Scaffold Split）到模型训练与评估的完整流程。

---

## 2. 数据集检查与预处理

**- 数据集是否可直接使用：**
不可以。原始数据集中存在数据格式错误、非法分子结构以及人为注入的超长异常分子，如果直接输入模型会导致特征提取失败或底层内存溢出（OOM）崩溃。

**- 是否存在重复、缺失、异常、非法 SMILES 等问题：**
经过统计分析，原始数据存在以下问题：
1. **缺失与格式错误**：`exp`（标签列）中包含非数值类型的脏数据；部分行存在空值。
2. **非法 SMILES**：存在无法被 RDKit 正常解析的无效 SMILES 字符串。
3. **异常数据（排雷）**：数据末尾包含具有数万个碳原子的超长直链异常分子（如 `CHEMBL_HUGE`），这类分子会导致 RDKit 底层计算拓扑结构时直接卡死。
4. **重复与冗余**：存在重复的分子结构记录；部分分子 SMILES 中含有盐离子片段（如 `.` 分隔的 `[Na+]` 等），需要去盐以保留主体结构。

**- 你做了哪些预处理：**
1. **基础清洗**：剔除了 `exp` 和 `smiles` 为空的行；使用 `pd.to_numeric` 强制将 `exp` 列转换为浮点数类型。
2. **SMILES 合法性与异常过滤**：利用 RDKit 过滤掉了无法转成 `Mol` 对象的非法 SMILES；针对异常数据，通过过滤 ID（包含 `HUGE`）以及强制截断长度超过 300 的 SMILES 字符串，成功排除了导致内核崩溃的“地雷”。
3. **去盐与规范化**：采用安全切分策略（按 `.` 切分并保留最长的主体片段）进行去盐，避免了调用 RDKit 复杂的 `MolStandardize` 模块引起的底层计算崩溃风险；随后统一转换为 Canonical SMILES（规范化）以保证同一分子的写法唯一。
4. **去重**：基于规范化后的 SMILES 进行了严格去重，最终得到了高质量的建模数据集。

## 3. 分子表示与输入处理

**- 你如何把分子转换为模型可读的输入：**
由于 SMILES 本质是字符串，无法直接输入给机器学习模型（如随机森林），必须将其转换为数值型矩阵。本项目使用 `RDKit` 提取了 **Morgan 分子指纹（Morgan Fingerprint）**。具体参数设置为半径 `radius=2`，维度 `nBits=2048`。这会将每个分子映射成一个包含 2048 个 0 和 1 的一维向量（表示分子中是否存在特定的子结构）。

**- 是否加入了额外特征或做了格式转换：**
本项目在 Baseline 阶段主要依赖 Morgan 指纹这一种结构特征，未额外拼接物理化学描述符（如分子量、LogP 等）。在格式转换上，将 RDKit 生成的 `BitVect` 类型强制转换为了 Numpy 数组（`np.array`），以便于后续拼接成二维特征矩阵 `X`。

**- 这些处理主要在 CPU 还是 GPU 上完成：**
主要在 CPU 上完成。RDKit 的底层算法依赖于 CPU 图遍历和哈希计算，不支持 GPU 加速。同时，后续使用的随机森林（RandomForest）也是典型的 CPU 密集型算法，不擅长处理 GPU 并行。

**- 是否考虑了速度优化：**
考虑到处理时间和内存占用，本项目没有开启多进程，而是利用了 Pandas 的 `apply` 方法进行串行批处理。为了优化训练速度，在随机森林的初始化中设置了 `n_jobs=-1`，调用了计算机所有的 CPU 核心进行并行训练。

## 4. Baseline 模型

**- 你的 baseline 模型是什么：**
本项目使用的 Baseline 模型是 **随机森林回归模型（Random Forest Regressor）**。

**- 为什么选择它作为起点：**
1. 随机森林能够很好地处理高维稀疏特征（如 2048 维的 Morgan 指纹）。
2. 它对特征的缩放不敏感，不需要进行复杂的标准化处理。
3. 相比于线性回归，它能自动捕捉特征之间的非线性关系；相比于深度学习模型，它训练速度极快，极易上手，非常适合作为建立深度学习模型之前性能的“基准参考线”。

## 5. 文献启发与模型设计

**- 你阅读了哪篇文章：**
主要参考了 MoleculeNet 基准测试的原始论文《MoleculeNet: A Benchmark for Molecular Machine Learning》（Wu et al., 2018），以及关于化学信息学中不同数据划分策略（随机划分 vs 骨架划分）对比的相关研究文献。

**- 从中提取了哪一点思路：**
从 MoleculeNet 等文献中提取了两个核心思路：
1. **数据泄漏风险（Data Leakage）**：在评估分子属性预测模型时，如果使用传统的随机划分，同一骨架的相似分子会同时出现在训练集和测试集中，导致模型过度依赖记忆相似结构，评估指标（R²）虚高。
2. **基线（Baseline）的重要性**：在尝试复杂的图神经网络（GNN）之前，应当先使用经典的 2D 分子指纹（如 Morgan 指纹）结合传统机器学习算法（如随机森林）建立一个可靠的基准线。

**- 你如何将它简化并融入自己的模型：**
结合上述文献思路与本次任务的要求，我进行了以下简化和应用：
1. **在数据集划分上**：坚决引入了 **Scaffold Split（基于 Murcko 骨架的划分）**。通过计算分子的核心骨架，将相同骨架的分子聚为一组，彻底切断了训练集和测试集之间的结构关联，真实模拟了新药发现中对“未知化学空间”的预测。
2. **在模型设计上**：放弃复杂的网络架构，仅使用 RDKit 提取简单的 2048 维 Morgan 指纹（Radius=2）作为输入，搭配开箱即用的随机森林回归器。这种极简的设计不仅运行极快（纯 CPU 几十秒内完成），而且成功跑出了 Baseline 水平（RMSE 0.9592），为后续的复杂模型提供了一个清晰的对比参考。

## 7. 实验设置与评价方式

**- 你的基本实验设置：**
1. **数据划分**：采用 Scaffold Split（骨架划分），随机种子设为 42，按 8:2 的比例划分为训练集（3024个样本）和测试集（756个样本）。这种划分方式严格防止了具有相似骨架的分子跨越训练集和测试集，能真实反映模型对“全新化学空间”的泛化能力。
2. **训练参数**：使用 `RandomForestRegressor`。初始参数设置为：决策树数量 `n_estimators=100`，并设置 `n_jobs=-1` 调用所有 CPU 核心并行训练，随机种子设为 42。
3. **运行环境**：Windows 系统，Python 3.12 虚拟环境，主要依赖库为 `pandas`、`rdkit`、`scikit-learn`，纯 CPU 计算。

**- 你使用了哪些评价指标：**
主要使用两个回归任务的经典指标：
1. **RMSE（均方根误差）**：作为主要评估指标，衡量预测值与真实值之间的偏差，数值越小越好。
2. **R²（决定系数）**：辅助指标，衡量模型能解释目标变量方差的比例，越接近 1 越好。

**- 你如何判断模型表现好坏：**
在骨架划分这种极难测试场景下，模型在测试集上取得了 **RMSE = 0.9592** 和 **R² = 0.3616** 的成绩。RMSE 小于 1.0 达到了 Baseline 的及格预期（说明平均预测偏差在 1 个 LogD 单位左右）。虽然 R² 不算高，但考虑到这是对全新骨架分子的盲测，且仅使用了 2D 指纹，这一结果证明模型已经具备了一定的结构-属性关联学习能力，但仍有较大的优化空间（需引入更好的特征或模型）。

## 8. 实验结果与分析

**- baseline 的结果：**
在 Scaffold Split 的严苛测试集（756个全新骨架样本）上，默认参数的随机森林（`n_estimators=100`）Baseline 表现如下：
*   **RMSE: 0.9592**
*   **R²: 0.3616**

**- 改进模型的结果：**
尝试对模型进行调参优化，将决策树数量增加到 300 棵，但为了防止过拟合强行限制了树的深度（`max_depth=15`, `min_samples_split=5`）。
*   **改进后结果：RMSE: 1.0273, R²: 0.2678**
*结论*：限制深度的操作导致模型严重“欠拟合”，性能反而不如 Baseline，因此最终保留了 Baseline 的默认参数。

**- 两者对比后你的结论：**
对于高维的分子指纹数据，随机森林需要足够的深度来捕捉复杂的化学子结构组合。强行剪枝（限制深度）会让模型无法学习到复杂的非线性关系。此外，盲目增加树的数量（100 -> 300）如果不配合良好的特征工程，并不能带来实质性的性能提升，只会徒增计算时间。

**- 目前模型存在的主要问题：**
1. **特征表征单一**：仅使用了 2D 的 Morgan 指纹（0/1 矩阵），丢失了分子的物理化学性质（如极性表面积、分子量等连续特征）以及 3D 空间构象信息。
2. **泛化能力遭遇瓶颈**：R² 较低（0.36），说明当测试集出现全新化学骨架时，模型预测误差较大，对未见结构的迁移预测能力不足。
3. **算法局限性**：随机森林属于传统的集成树模型，在捕捉复杂的分子图结构方面，上限不如深度学习（如 GNN 图神经网络）。
